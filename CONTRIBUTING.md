# Contributing to TokenDance

Thanks for your interest in contributing! TokenDance is an open-source AI infrastructure project family.

## Code of Conduct

All contributors must follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## How to Contribute

1. **Fork** the repository
2. **Create a branch** (`git checkout -b feat/my-feature`)
3. **Make your changes** — keep commits small and focused
4. **Add tests** if applicable
5. **Run the test suite** (`go test ./...` or `pnpm test`)
6. **Submit a pull request** — fill out the PR template

## Pull Request Guidelines

- One PR = one logical change
- Link related issues (`closes #123`)
- Update docs if you change public APIs
- Keep diffs reviewable — split large changes into multiple PRs

## Development Setup

Each repository has its own development guide in `README.md`. Common prerequisites:

- **Go**: 1.22+
- **Node.js**: 22+
- **pnpm**: 10+
- **Rust**: latest stable (for TokenDanceCode)
- **Docker**: for containerized development

## Questions?

Open a [GitHub Discussion](https://github.com/orgs/TokenDanceLab/discussions) or join our community channels.
