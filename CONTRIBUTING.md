# Contributing to TokenDance

Thanks for your interest in TokenDance. The organization publishes a mix of
public projects, documentation, protocol contracts, and corresponding source.
Contribution scope and support differ by repository.

## Code of Conduct

All contributors must follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## How to Contribute

1. Read the target repository's `README.md`, contribution notes, and issue tracker.
2. Confirm that the change belongs to that repository and is within its current scope.
3. Create a focused branch and keep the change reviewable.
4. Run the repository's documented checks and update public documentation when behavior changes.
5. Submit a pull request using that repository's template.

## Pull Request Guidelines

- One PR = one logical change
- Link related issues (`closes #123`)
- Update docs if you change public APIs
- Keep diffs reviewable — split large changes into multiple PRs

## Questions?

Use the target repository's issue tracker for scoped questions. For product and
service entry points, start at [tokendancelab.com](https://tokendancelab.com).
Do not use public issues for vulnerability reports; follow
[SECURITY.md](SECURITY.md).
