## Docs and source · 文档与源码

- **Code:** [English docs](https://code.tokendancelab.com/docs/overview) · [中文文档](https://code.tokendancelab.com/zh/docs/overview). The current Rust CLI is a development preview with a simulated provider; model integration is still in development.
- **Account:** [Developer docs](https://account.tokendancelab.com/developers) · [开发者文档](https://account.tokendancelab.com/zh/developers). Public OIDC contracts and integration examples; the service implementation is private.

| Public repository | Scope / 范围 |
|---|---|
| [tokendance-code](https://github.com/TokenDanceLab/tokendance-code) | Experimental Rust CLI and libraries / 实验性 Rust CLI 与库模块 |
| [tokendance-chat-source](https://github.com/TokenDanceLab/tokendance-chat-source) | Corresponding Source snapshots for identified Chat releases / 指定 Chat 版本的对应源码快照 |

Code 当前默认 CLI 使用模拟 Provider，真实模型接线仍在开发。Account 公开 OIDC 契约与接入示例，服务实现保持私有。公开网站、公开协议和公开源码是三种不同的开放范围；各产品的能力与边界以对应文档为准。
