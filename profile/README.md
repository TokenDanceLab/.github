# TokenDanceLab

**AI-native infrastructure for the next generation of applications.**

TokenDance builds open-source developer tools for AI engineering teams — multi-agent collaboration, unified model API access, and single sign-on identity.

## Products

| Product | Description | Site |
|---------|-------------|------|
| **AgentHub** | IM-form multi-agent collaboration platform | [hub.vectorcontrol.tech](https://hub.vectorcontrol.tech) |
| **Gateway** | Unified model API gateway — one key for every model | [tokendance.vectorcontrol.tech](https://tokendance.vectorcontrol.tech/en/docs/gateway) |
| **TokenDance ID** | OIDC identity provider — one account everywhere | [id.vectorcontrol.tech](https://id.vectorcontrol.tech) |
| **TokenDanceCode** | Local coding-agent CLI runtime | [code.vectorcontrol.tech](https://code.vectorcontrol.tech) |
| **TokenDance Chat** | Real-time agent interaction chat | [chat.vectorcontrol.tech](https://chat.vectorcontrol.tech) |
