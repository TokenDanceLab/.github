# TokenDanceLab

**AI-native infrastructure for the next generation of applications.**

TokenDance builds open-source developer tools for AI engineering teams — multi-agent collaboration, unified model API access, and single sign-on identity.

## Products

| Product | Description | Site |
|---------|-------------|------|
| **AgentHub** | Multi-agent collaboration platform | [hub.tokendancelab.com](https://hub.tokendancelab.com) |
| **TokenDance Gateway** | Unified model API gateway — one key for every model | [tokens.tokendancelab.com](https://tokens.tokendancelab.com) |
| **TokenDance ID** | OIDC identity provider — one account everywhere | [id.tokendancelab.com](https://id.tokendancelab.com) |
| **TokenDanceCode** | Local coding-agent CLI runtime | [code.tokendancelab.com](https://code.tokendancelab.com) |
| **TokenDance Chat** | Real-time agent interaction chat | [chat.tokendancelab.com](https://chat.tokendancelab.com) |
