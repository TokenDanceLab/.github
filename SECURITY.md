# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any TokenDance project, **please do not open a public issue**.

Report it through GitHub Security Advisories:

1. Go to the repository's **Security** tab
2. Click **Report a vulnerability**
3. Describe the issue with as much detail as possible

We aim to acknowledge reports within **48 hours** and provide a fix timeline within **5 business days**.

## Supported Versions

| Version | Supported |
|---------|:---------:|
| Latest release | ✅ |
| Previous release | ✅ (security patches only) |
| Older releases | ❌ |

## Scope

Security reports are welcome for all public TokenDanceLab repositories:

- `AgentHub`
- `tokendance-gateway`
- `tokendance-id`
- `TokenDanceCode`
- `tokendance-chat`
- `metapi-go`
- `tokendance-site`

Infrastructure security issues (DNS, TLS, server configuration) should be reported to the same advisory channel.
